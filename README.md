# VaaniSpec

VaaniSpec is a lightweight, minimalist frontend prototype for “Hinglish-to-Prod”: users can drop in a voice note or type a rough product idea and preview the four artifacts the finished Sarvam-powered experience would generate — a product overview, architecture, API schema, and voice pitch.

This prototype is intentionally static and contains no API key, backend, database, build step, or external runtime dependency. It is ready to publish from the repository root with GitHub Pages. The generated output is representative demo content so the interface can be reviewed without credentials.
